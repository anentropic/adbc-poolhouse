Build `AsyncRecordBatchReader` — the composition wrapper over a sync `pyarrow.RecordBatchReader` —

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| loop → worker (`_pull`, `close`) | blocking Arrow C calls cross `to_thread`; StopIteration must not leak; cancel must abort cleanly |
| live reader C-stream → checked-in connection | read-after-checkin is a use-after-free hazard |
| cancelled pull → connection pool | a cancelled/timed-out pull must not leave the connection checked out |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | Denial (use-after-free/segfault) | read-after-checkin on a live reader | mitigate | Reader-lifetime binding via the `_release_arrow_allocators` reset backstop + `_detached` guard (D-29-12) → native `pyarrow.lib.ArrowInvalid`, never a segfault; proven by `test_reader_lifetime.py` (STREAM-04/EDGE-33) on DuckDB + Snowflake cassette, asyncio x trio |
| T-29-02 | Denial (pool leak on cancel) | `__anext__` cancelled/timed-out pull | mitigate | `cancellable_offload(..., on_abort=owner.invalidate)` fires the cursor's `adbc_cancel` once + invalidates → `pool.checkedout() == 0`; proven by `test_reader_cancel.py` (STREAM-05) |
| T-29-04 | Denial (resource leak) | unclosed reader | mitigate | Warn-only `__del__` `ResourceWarning` + reset-event checkin backstop; proven by `test_reader_resource.py` (EDGE-22/23) |
| T-29-06 | Tampering (StopIteration→RuntimeError leak) | `_pull` worker boundary | mitigate | Worker-side `except StopIteration: return _EXHAUSTED`; `__anext__` raises `StopAsyncIteration` on the sentinel — proven by `test_reader_stream.py` exhaustion case |
| T-29-SC | Tampering | npm/pip/cargo installs | accept | No packages installed (RESEARCH Package Legitimacy Audit: none) |
</threat_model>
